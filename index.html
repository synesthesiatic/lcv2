One passphrase, one strong pass of AES-256-GCM per file. The passphrase is stretched through Argon2id — a slow, memory-hard function built specifically to make guessing expensive — so there's no separate key file to lose, mix up, or leave lying around unprotected.

On sharing a passphrase in person: a passphrase you say out loud is only as strong as the words in it. Words chosen for personal meaning (names, pets, inside jokes) are guessable — by people who know you, or by a dictionary attack — no matter how long the resulting string looks. The "Generate memorable phrase" button picks several words uniformly at random from a fixed list, which is what actually makes a spoken passphrase both memorable and hard to guess.

How it works: your passphrase is stretched into a 256-bit key with Argon2id (a memory-hard function, not a fast hash) using parameters stored alongside the ciphertext. Each batch gets its own random salt, and each file a fresh random nonce, then one pass of AES-256-GCM — which fails loudly, not silently, if the passphrase, salt, or a single byte is wrong. Nothing here leaves your browser: files are processed locally. The only network requests this page makes are for the Argon2 library code and the web fonts, from public CDNs — never your files or passphrase.
